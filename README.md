# Machine Learning Training Projects

## 📌 Overview

This repository contains machine learning exercises and implementations completed during a certification training session.

The training provided hands-on exposure to fundamental machine learning concepts, including forward propagation, backward propagation, neural network fundamentals, and image classification using the Fashion-MNIST dataset.

The repository contains the implementations practiced during the training sessions.

---

## 🎯 Objectives

- Understand the basic workflow of machine learning models.
- Learn the fundamentals of neural networks.
- Understand forward propagation and backward propagation.
- Work with image classification data.
- Explore the Fashion-MNIST dataset.
- Implement basic ML concepts using Python.

---

## 🛠️ Technologies Used

- Python
- NumPy
- Machine Learning
- Neural Networks
- Fashion-MNIST

---

## 📂 Contents

### 1. Forward Propagation

`1forwardpropogation.py`

This implementation demonstrates the basic concept of forward propagation in a neural network, where input data is passed through the network to produce an output.

### 2. Backward Propagation

`1backwardpropogation.py`

This implementation demonstrates the basic concept of backward propagation, which is used during neural network training to calculate and update model parameters.

### 3. Fashion-MNIST Label Predictor

`fashion_mnist label predictor`

This exercise works with the Fashion-MNIST dataset for image classification.

The objective is to use a machine learning model to predict the class/label associated with an input fashion image.
